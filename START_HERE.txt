NASHIK FIRST DRIVE v2.0 — FULL CITY BUILDER + MINIMAP FIX

The College Road world is included and still opens immediately.
The entire Nashik map is NOT predownloaded in this ZIP. To create the city,
your Mac needs an internet connection to retrieve licensed OpenStreetMap data.

ADD WHOLE NASHIK (one-click Mac):
  1. Unzip this file.
  2. Open the Nashik-Drive-main folder.
  3. Double-click BUILD_FULL_NASHIK_CITY.command.
     (If macOS blocks it, right-click -> Open.)
  4. The command downloads mapped road/building data in cached chunks,
     generates city-world.json, and opens the game automatically.
  5. Existing College Road remains in world.json; it is not overwritten.

OPEN ONLY THE EXISTING COLLEGE ROAD WORLD:
  Double-click OPEN_NASHIK_STUDIO.command and choose Preview Game,
  or visit http://localhost:8000/?college=1

CONTROLS:
  W/S = accelerate/reverse, A/D = steer, E = exit/enter, M = whole-city map.
  The corner minimap shows only streets near the player's TRUE position.

IF DOWNLOAD FAILS:
  Close the Terminal and rerun BUILD_FULL_NASHIK_CITY.command.
  Successful chunks are cached and will not be redownloaded.
  You can also run: python3 scripts/build_nashik_city.py --input /path/to/nashik.geojson

IF TERMINAL SAYS PORT 8000 IS IN USE:
  Stop the other server with Control+C, then open the command again.

PUBLISH ON VERCEL:
  After the city file is generated, run npm run build (Node required),
  then deploy dist/. Or commit city-world.json and let Vercel rebuild.

LIMITATIONS:
  City geometry depends on OSM coverage, approximate road widths and
  estimated building heights. This does not yet include terrain, photos,
  accurate storefronts, lane AI, or missions. City footprint is an
  approximate urban extent, not Nashik's official administrative boundary.
  OSM attribution is required: © OpenStreetMap contributors — ODbL 1.0.

NEW IN v2.1 — CITY EXPLORER
  1. Double-click PLAY_NASHIK_CITY.command.
  2. When asked, select the city-world.json generated by your previous full-city builder.
  3. Start the game, click MAP, choose College Road / Panchavati / Satpur /
     Nashik Road or search a mapped road name.
  4. Click TELEPORT TO ROAD to inspect that street; the smaller minimap follows you.
  See README_CITY_EXPLORER.md for full instructions.
